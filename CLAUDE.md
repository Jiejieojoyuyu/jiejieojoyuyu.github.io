## Project Overview

This is a GitHub Pages personal homepage for 黄煜杰 (Huang Yujie), hosted at `Jiejieojoyuyu.github.io`. It's a static site consisting of a single `index.html` file in Chinese (zh-CN).

## Deployment

The site is deployed via GitHub Pages from the `main` branch. Pushing to `main` automatically publishes changes. There is no build step — the raw HTML is served directly.

## Architecture

Single-page static site with no framework, no build tools, and no dependencies. All content lives in `index.html`. The README identifies the site owner and email contacts.
